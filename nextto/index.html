FAQ

Is NextTo free?

Yes. Browsing, voting, and downloads on the site are free.

What do I need to run it?

A web browser. Sign in with GitHub to vote or submit a demand.

Does NextTo collect personal data?

GitHub sign-in stores your profile and email so each person can upvote once. There is no analytics or advertising.
