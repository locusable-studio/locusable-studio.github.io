FAQ

Is Here Links free?

Yes. Free to use.

What does Here Links do?

A native iPhone client for self-hosted linkding. Browse bookmarks, read in-app, and save from the share sheet.

What do I need to run it?

iPhone with iOS 26, plus a linkding server with an API token.

Does Here Links collect personal data?

No. It talks only to the linkding servers you own.

What is linkding?

linkding is a self-hosted bookmark manager. It’s small, fast, and easy to set up.

Can I connect more than one server?

Yes. One instance or several, mixed into a single feed.
