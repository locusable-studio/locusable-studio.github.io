Made for linkding

  • Servers Connect one linkding instance or several, and browse them in one feed.
  • Share Save links from other apps with the share sheet.
  • Open Read in the in-app browser, and keep HTML snapshots with your API token.

FAQ

Is Here Links free?

Yes. Free to use.

What do I need to run it?

iPhone with iOS 26, plus a linkding server with an API token.

Does Here Links collect personal data?

No. It talks only to the linkding servers you own.

Can I connect more than one server?

Yes. One instance or several, mixed into a single feed.
