FAQ

Does it work with every button?

Here Button works with controls exposed through macOS Accessibility. Some apps and buttons are not supported. See the compatibility list or report an issue.

Will clicking a pin switch apps?

By default, Here Button brings the source app forward before triggering its control. You can enable background triggering for individual pins; whether it works depends on the source app.

What do I need to run it?

macOS 14 or later, with Accessibility permission enabled for Here Button.

Is Here Button free?

Yes. Here Button is free to download and use, with no account or purchase required.

How do I install it?

Download the DMG, open it, and drag Here Button into Applications. Launch it from Applications and allow Accessibility access in System Settings when prompted.

How do I update it?

Choose “Check for Updates…” from the menu bar to check for a new version. You can also download the latest installer using the Download link above.
